One-line slogan for a Solana wallet agent, entered in make.fun's "One-Line Slogan for a Solana Wallet Agent" bounty ($2, winner-takes-all).

> Your Solana wallet's doorman is Gus: he checks every guest twice, pockets nothing, and only opens the door for you.

20 words, 115 bytes, one line. The doorman image is the whole pitch: a wallet agent that checks everything, takes nothing, and only ever opens the door for you. Picked by internal pairwise judging (judge criteria, lexicographic, margin-weighted) over two other candidates — see `leaderboard-top10.md`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the slogan to `/output/entry.txt`. No secrets, no network, no dependencies.
